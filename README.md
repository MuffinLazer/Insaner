# Insaner
A Github repository for everything HUD related cause I'm a lazy bum

Insaner HUD
	https://github.com/MuffinLazer, a HUD that can be worn and has a multitude of features such as facial tracking, GPS display, and temperature and humidity.
	I am proposing making a helmet featuring a HUD as a project to further my skills as an engineer. It will be shaped around my head and I will design it so it will self regulate cooling to ensure it does not overheat. Creating this helmet will allow me to pursue a degree in robotics engineering as it is a powerful tool in a resume. This helmet will also have an easy to interact with OS allowing for edits easily with the raspberry pi and its os system. 
	Following this, the helm will use extensive sensors to display on the hud allowing for a hot swappable amount of information on the HUD.
	This project is important for demonstrating my skills with the mechatronics field, such as raspberry pis, Arduino, sensors, and software development. It will also include 3D modeling, wiring, and networking for the construction. 
Technologies required
Raspberry pi
Arduino 
Adafruit sensors, displays, and cameras 
Framework/linux compatibility
